## Mousewar

A 30-second arcade reaction game. Click the glowing target as fast as
possible, chain hits within 1s to build up to a x10 combo multiplier, and
beat your local high score.

Zero npm dependencies — plain HTML/CSS/JS with ES modules.

```
npm run dev    # serve at http://localhost:5173
npm test       # run the game-logic test suite (node --test)
```

Then open the printed URL and click PLAY.
